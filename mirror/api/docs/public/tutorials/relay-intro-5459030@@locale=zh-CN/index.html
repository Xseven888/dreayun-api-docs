不设置，由平台全局策略决定 |\r\n| **智能自动**（`auto`） | 跨所有可访问渠道，综合速度 / 成功率 / 价格自动选最优 |\r\n| **价格优先**（`price`） | 选当前可用渠道中单价最低的 |\r\n| **速度优先**（`speed`） | 选当前可用渠道中响应速度最快的 |\r\n| **成功率优先**（`success_rate`） | 选近期成功率最高的渠道 |\r\n\r\n### 三种设置方式\r\n\r\n路由模式支持三种设置方式，**优先级从高到低**：\r\n\r\n```\r\n模型名后缀 \u003e 请求体 provider.sort \u003e 令牌路由模式\r\n```\r\n\r\n---\r\n\r\n#### 方式一：模型名后缀（最简单，单次生效）\r\n\r\n在模型名末尾加上冒号后缀，**无需修改任何配置**，即可对本次请求应用指定路由模式。\r\n\r\n```json\r\n{\r\n \"model\": \"gpt-4o:price\",\r\n \"messages\": [...]\r\n}\r\n```\r\n\r\n支持的后缀：\r\n\r\n| 后缀 | 效果 | 兼容写法（OpenRouter 风格）|\r\n|---|---|---|\r\n| `:price` | 价格最低 | `:floor` |\r\n| `:speed` | 速度最快 | `:nitro` |\r\n| `:success_rate` | 成功率最高 | `:stable` |\r\n\r\n\u003e 后缀只影响路由选择，不会传递给上游模型。不在列表中的后缀（如 `:beta`、`:v2`）会原样保留在模型名中。\r\n\r\n---\r\n\r\n#### 方式二：请求体 `provider.sort`（单次生效）\r\n\r\n在请求体中加入 `provider` 字段，**仅对本次请求生效**，不影响令牌的持久配置。\r\n\r\n```json\r\n{\r\n \"model\": \"gpt-4o\",\r\n \"messages\": [{\"role\": \"user\", \"content\": \"你好\"}],\r\n \"provider\": {\r\n \"sort\": \"speed\"\r\n }\r\n}\r\n```\r\n\r\n`provider.sort` 支持的值：`price` / `speed` / `success_rate` / `floor` / `nitro` / 方式三：令牌路由模式（推荐，持久生效）\r\n\r\n在**创建或编辑令牌**时选择路由模式，**对该令牌的所有请求永久生效**，调用方无需额外操作。\r\n\r\n操作路径：令牌管理 → 新建/编辑令牌 → 路由优先模式\r\n\r\n| 选项 | 适用场景 |\r\n|---|---|\r\n| 系统默认（不设置） | 无特殊需求，跟随平台全局策略 |\r\n| 智能自动（auto） |
